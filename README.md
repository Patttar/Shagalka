# Шагалка

Кликабельный прототип мобильного приложения: маршруты для прогулки рядом с вами — по времени или по шагам.

**Открыть на телефоне:** https://patttar.github.io/Shagalka/

Чтобы открывалось как приложение, добавьте страницу на экран «Домой»:
- iPhone (Safari): «Поделиться» → «На экран „Домой“»;
- Android (Chrome): меню ⋮ → «Добавить на главный экран».

Без геопозиции можно посмотреть демо-район: https://patttar.github.io/Shagalka/?demo

## Что умеет

- Сразу при входе определяет геопозицию и показывает адрес на плашке.
- Строит до 6 настоящих пешеходных маршрутов от вашей точки — по улицам и тропинкам, через реальные парки и достопримечательности (замкнутые или в одну сторону), длина подгоняется под цель.
- Настройки подбора: время или шаги, пресеты и своё значение слайдером.
- Превью маршрута: линия на карте, галерея мест по пути, время, шаги, путь.
- Прогулка: таймер, прогресс цели, пауза, подтверждение завершения, итоги. С настоящим GPS считает пройденное по треку; на демо-районе идёт ускоренно ×15.
- История: итоги недели, детали прогулки, удаление свайпом влево с отменой.
- Избранное: сердце на превью и в деталях прогулки, вкладка «Избранное» на главной.
- Профиль: вес и длина шага для расчёта калорий и шагов.
- Светлая и тёмная тема — как в системе; карта переключается вместе с темой.
- Шторки закрываются крестиком, жестом «назад» и свайпом вниз за верхнюю часть.

Данные хранятся только в браузере телефона (localStorage).

## Устройство

Статичный сайт без сборки: `index.html`, `styles.css`, `app.js`, `routing.js`, `icons.js` (иконки Lucide). Карта — Leaflet + OpenStreetMap. Цвета и типографика повторяют дизайн-систему Veritheme из Figma.

Откуда данные (`routing.js`, всё бесплатно и без ключей; для публичного запуска нужны свои серверы или платные API):
- места — OpenStreetMap (Overpass, несколько зеркал параллельно) и статьи Википедии с геометкой;
- фото — Википедия и Wikimedia Commons; если фото нет, карточка показывается без него;
- пешеходные маршруты — OSRM (routing.openstreetmap.de), профиль «пешком»;
- адрес — Nominatim. Время, шаги и калории считает само приложение.

Запуск локально: `python -m http.server 8000` в папке проекта и открыть http://localhost:8000.
